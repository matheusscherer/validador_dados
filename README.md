# Data Validator

Dirty CSV in. Clear audit report out.

Python script that reads a CSV, runs quality checks and writes:

- `relatorio_auditoria.md` — findings by severity
- `auditoria.db` — SQLite with flagged rows and history

The example uses sales data. The engine works for any tabular spreadsheet. The sample base is **synthetic**, generated by the code itself, with intentional errors.

**Author:** [Matheus Scherer](https://github.com/matheusscherer) · Porto Alegre, Brazil

---

## What it does

| | |
|---|---|
| **Input** | CSV (`dados_vendas_bruto.csv` or yours) |
| **Checks** | duplicates · null in critical fields · outlier (IQR) · negative values · dates · text with spaces · `qty × unit ≠ total` |
| **Output** | Markdown + SQLite |

Without a CSV in the folder, it generates 500 synthetic rows with seed 42 — only to show the report.

## Stack

Python 3.10+ · Pandas · NumPy · SQLite · pytest · GitHub Actions · MIT

## How to run

```bash
git clone https://github.com/matheusscherer/validador_dados.git
cd validador_dados
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"

python -m validador_dados.main
pytest -v
```

Regenerate the committed example:

```bash
PYTHONPATH=src python scripts/gerar_exemplo.py
```

## Evidence / demo

Report generated **by the code**, not written by hand:

- [docs/relatorio_exemplo.md](docs/relatorio_exemplo.md) — 505 synthetic rows, 89 records with at least one issue (17.6% in this run)
- Tests: correct calculation does **not** flag; `3 × 10 ≠ 25` **does** flag; critical null; duplicate; report contains the finding type
- CI: pytest on Python 3.10 / 3.11 / 3.12

This is **not** a client result. It is the engine output on the sample base.

---

## Limitations

- Outlier detection is simple IQR. On skewed distributions it over-flags — 61 outliers in this run.
- Dates use a fixed 2020–2026 window in `rodar_auditoria_completa`.
- Not a continuous profiler, not Great Expectations, no versioned schema.
- SQLite is a run dump, not a warehouse.

---

## What this is NOT

- Not a real client case or operational metric.
- Not corporate data engineering (no dbt, Airflow, warehouse).
- Not a fraud detection system.
- Does not prove advanced SQL beyond `to_sql`.
